# My First PHP Blog

Навчальний проєкт блогу, створений під час вивчення **PHP**, **MySQL**, **Twig**, **Composer** та принципів побудови MVC-додатків.

Проєкт демонструє створення повноцінного CRUD-застосунку з використанням маршрутизації, шаблонізатора Twig, роботи з базою даних через власний Data Mapper та пагінації.


## 📌 Основні можливості

- Перегляд списку статей
- Перегляд окремої статті
- Пагінація записів
- Робота з базою даних MySQL
- SEO-friendly URL (slug)
- Шаблонізатор Twig
- MVC архітектура
- Data Mapper для роботи з БД
- Dependency Injection
- Composer autoload
- Bootstrap для інтерфейсу

## 🛠 Технології

- PHP 8
- MySQL
- Twig
- Composer
- Bootstrap 5
- HTML5
- CSS3
